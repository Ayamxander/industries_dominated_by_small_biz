# industries_dominated_by_small_biz
Which industries have the highest number of establishments but the lowest total employment level?

**Rationale for the Project** Software and service providers with this data can target an entire sector with specialized tools—such as all-in-one CRM, scheduling, or billing software—tailored to non-technical solo operators who lack dedicated IT or operations teams. Also, private equity firms and buyers could use it to acquire and combine many small, independent operations into a single, cohesive business. This consolidates market share, reduces redundant overhead (like administrative or marketing costs), and boosts profit margins through economies of scale.
Utility: Identifies "fragmented" industries dominated by sole proprietors or small consultancies.

**Code summary** The code pulls the total number of establishments in every industry then divides total number of employees by total number of establishments to find the average number of employees per establishment.

**Dataset(s) Used** The dataset used is the official QCEW (Quarterly Census of Employment and Wages) data for California from 2004-2007, gotten from data.gov website.
